Quantity Tiers

The 12-tier range model covering 1–10,000 pieces. Add, remove, or reorder tiers; mark a tier "Review" to route it to production review instead of instant checkout. Orders above the top tier's max are rejected with a "contact us" message.

Internal Cost Settings

Minimum Target Margin

⚠ Placeholder default (20%) — needs Trey's real number. Quotes priced below this margin get an internal warning badge in the quote detail. Informational only — never blocks a customer from checking out.

Garment Pricing

Set a price per quantity tier for each garment ("Fixed Tier"), or switch to cost/margin-based pricing where the selling price is computed automatically. Rows badged Estimated came from the Phase 2 placeholder migration and need your review before you rely on them.

Global Price Adjustment

Bump every garment's price at once. Fixed-tier garments scale all tier prices; margin-based garments get their Garment Cost input increased (so the selling price moves on its own via the margin formula, not double-adjusted). This is logged and cannot be undone automatically — export/note current prices first if you might want to revert.

Admin Action Log
